# **Landscapes Reimagined: Genesis - Version 3.3.0**
### *The Revival Update*

### **Introduction**
Version **3.3.0** is the biggest update to *Genesis* since its release, reviving the pack with **Create 6.0**, a large set of new Create addons and storage mods, a rebuilt questbook, and a switch from **EMI** to **JEI**.

Alongside the new content, the pack's KubeJS scripts have been reorganized, custom content has moved to its own `genesis:` namespace, and **Create Foundry** has been expanded with moulds for every molten metal. Several unstable, redundant or resource-intensive mods have been removed to improve stability and load times.

---

### **Overview**
**Create** has been updated from v0.5.1 to **v6.0.8.1**, adding package logistics, chain conveyors, stock tickers and more. New addons build on it: **Create: Connected** (replacing Create Utilities), **Create: Dragons Plus**, **Create Contraption Terminals**, **Create Crafts & (More) Additions** and **Create: Jetpack Curios**. **Create: Enchantment Industry** has been updated to v2.5.4.

Storage has been expanded with **Sophisticated Backpacks**, **Sophisticated Storage** and **Sophisticated Storage In Motion**, and **Farming for Blockheads** markets now sell crops, seeds, saplings, flowers and mushrooms from across the pack.

**Create Foundry** now has **Ingot**, **Gem** and **Block Moulds** for every molten metal, including Advanced Netherite, Ad Astra and Better End metals. Block Moulds replace the old molten-to-block compacting recipes.

**EMI** has been replaced by **Just Enough Items** and **JEI++**, which keeps the recipe tree players loved while loading recipes only once. **Journeymap** replaces Xaero's maps, and **OpenLoader** replaces Global Data- & Resourcepacks.

The questbook has been rebuilt with better rewards, descriptions and layouts, three new chapters, and item tasks in place of many checkmark quests.

For a full list of updated mods, view the detailed changelog on GitHub:

## **KubeJS & Script Changes**
### **Script Reorganization**
- **All Scripts**: Reorganized server and startup scripts into `Compat` and `Mod Adjustments` folders, split by recipe type, to match the formatting used in *Create - Forge Frontier*. All custom recipes now use `genesis:` recipe ids.

### **Asset Changes**
- **Assets\Create Foundry**: Added textures for every new Ingot, Gem and Block Mould, the Empty Block Mould and the Block Mould Blueprint.
- **Assets\KubeJS**: Updated the textures for Netherite Dust, Incomplete Netherite Dust, Netherite Specks and Magnetite.
- **Assets**: Removed non-essential assets, including the EMI recipe filters.

### **Startup Script Changes**
- **Startup Scripts\Landscapes Reimagined**: Moved custom items, blocks and fluids from the `kubejs:` namespace to `genesis:`.
- **Startup Scripts\Landscapes Reimagined\Custom_Fluids**: Moved the molten metal fluids to the `createfoundry:` namespace so they blend in with Create Foundry.
- **Startup Scripts\Landscapes Reimagined\Moulds**: Added the new Ingot, Gem and Block Moulds and the Block Mould Blueprint.
- **Startup Scripts\Landscapes Reimagined\Legacy_Items**: Kept the old `kubejs:` items, blocks and fluids registered so existing worlds don't lose them.

### **Server Script Changes**
- **Server Scripts\Compat\Create Foundry\Mould_Recipes**: Added filling and pressing recipes for every Ingot, Gem and Block Mould, along with the Block Mould Blueprint and Empty Block Mould recipes.
- **Server Scripts\Compat\Create Foundry\Compacting_Recipes**: Replaced the molten-to-block compacting recipes with Block Moulds.
- **Server Scripts\Compat\Create Foundry\Mixing_Recipes**: Added steel ingot and block melting recipes.
- **Server Scripts\Compat\Landscapes Reimagined\Mixing_Recipes**: Updated the Liquid Dragon's Breath recipes to use Create: Dragons Plus's Dragon's Breath.
- **Server Scripts\Compat\Landscapes Reimagined\Legacy_Item_Conversion**: Automatically converts old `kubejs:` items in inventories, Ender Chests and containers, and swaps placed legacy blocks. Added crafting recipes for legacy items and Mechanical Mixer recipes for legacy fluids.
- **Server Scripts\Mod Adjustments\Deeper Darker**: Added missing crushing and smelting recipes for Deeper and Darker lead.

### **Client Script Changes**
- **Client Scripts\Landscapes Reimagined\Legacy_Items**: Hides legacy items from JEI and explains them in their tooltips.

### **Data Changes**
- **Data\Farming for Blockheads**: Added market entries for crops, seeds, saplings, flowers and mushrooms from across the pack, including VanillaBackport items.
- **Data\Deeper Darker**: Added Resonarium tool and armor smithing recipes.
- **Data\Delightful Creators**: Added a beetroot soup emptying recipe.
- **Data\Incendium**: Added an elytra upgrade recipe.
- **Data\Utility Belt**: Added a Utility Belt upgrade recipe.

#### **⚠️ Updating an Existing World?**

- **Back up your world first.** This update makes major changes to Create and many of its addons.
- Old `kubejs:` items convert automatically when you log in, open a container or right-click it. Items in storage the scripts can't reach can be crafted into their new versions.
- Fluids from the old `kubejs:` molten metals can be converted by running them through a Mechanical Mixer.
