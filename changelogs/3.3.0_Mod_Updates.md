# **Modpack Mod Updates: Version 3.3.0**

## **Introduction**

Version **3.3.0** brings almost every mod in *Genesis* up to date. The biggest jumps are **Create** (0.5.1 → 6.0.8.1), **Create: Enchantment Industry** (1.2.16 → 2.5.4) and **Deeper and Darker** (1.2.6 → 2.0.0), which are what made this update's new quests, recipes and Create addons possible.
